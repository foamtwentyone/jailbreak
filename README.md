# Cellbreak

Мод для Minecraft (Fabric, 1.21.1) по мотивам «побега из тюрьмы»: одни игроки —
заключённые, другие — охрана, свободные посты охраны занимают NPC.

## Текстуры

Все текстуры генерируются скриптом, ручной графики нет:

```
python3 tools/gen_textures.py src/main/resources/assets/cellbreak
python3 tools/preview.py src/main/resources/assets/cellbreak preview.png
```
